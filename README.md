# Бэсти — сайт студии маникюра (версия 2)

Обычный статичный сайт без сборки: открыть `index.html` в браузере.

| Папка / файл | Что внутри |
|---|---|
| `index.html` | вся страница |
| `css/style.css` | основа и **дизайн-система** — переменные в начале файла (цвета, размеры текста, тени, рамки) |
| `css/shapki.css`, `oblozhki.css`, `mastera.css`, `gosti.css`, `raboty-otzyvy.css` | шапка, обложка, мастера и основательница, «В гостях у бэсти», работы и отзывы |
| `js/main.js` | меню, купон, папки услуг, веер работ, отзывы, клавиша **G** — сетка поверх страницы |
| `js/prices.js` | прайс (папки услуг) |
| `js/karta.js` | Яндекс Карта; ключ API вписать в `YMAPS_KEY` |
| `assets/` | фото, видео, иконки, логотипы |
| `dizajn-sistema.html` | справочник: цвета, шрифты, сетка, кнопки, окна, иконки |

Сетка: 12 колонок, зазор 8 px, поля 16 px. Заголовки — колонка 2, тексты — колонка 8, правый край — колонка 11.

Перед запуском: снять `noindex` в `index.html`, вписать ключ Яндекс Карт, заменить пометки `[ждём: …]`.
