# Бэсти — сайт, концепт 2 (рабочая версия)

Обычный статический сайт: `index.html`, `css/style.css`, `js/prices.js` (прайс по папкам — править здесь), `js/main.js` (меню, окно первого визита, папки прайса, видео), `assets/` (фото, видео, логотипы, иконки), `fonts/`.
Внешних запросов нет. Стоит `noindex` — снять перед запуском боевого сайта.

Локально: `python3 -m http.server 38001 --bind 127.0.0.1` из этой папки → http://127.0.0.1:38001/ (в VSCode — вкладка «Порты»).

## Сравнение вариантов прямо на сайте

`js/variants.js` рисует справа вверху служебную панель «Варианты» (простая, без оформления сайта; появляется, только когда на странице есть блок с вариантами). Блок с вариантами — обёртка `data-variant-group="<ключ>" data-group-label="<название>"`, внутри секции `data-variant="<id>" data-label="<подпись>"`. Выбор запоминается в браузере и открывается ссылкой `?<ключ>=<id>` (например `?header=B`). Перед сдачей: оставить выбранный вариант, удалить остальные и подключение `variants.js`.
